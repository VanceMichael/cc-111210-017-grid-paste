# 展位网格页面
两条业务行A-01、B-02含功率、联系人和只读公式。支持反向排序、数字locale切换和人工并发更改。页面在contenteditable单元格接收浏览器paste事件中的TSV，按当前视觉矩形逐格校验，功率大于100拒绝，其他单元格仍可成功。
回执写在页面status区，带业务键、列、版本和状态。查看器侧的批量录入实现在 `src/grid.mjs`：录入前只读核对列身份（`data-column`/`data-cell`）、单元格 `data-type`、行 `data-version` 与 `data-readonly` 区域，先输出变更预览，操作者确认后才写入；写入只使用授权剪贴板（浏览器上下文授予 clipboard 权限，`navigator.clipboard.writeText` 后 Ctrl+V）触发页面 paste 处理，不直接调用页面函数或改写行数组。粘贴块按业务键与可视矩形切块，排序、隐藏列和筛选掉的行都不会造成位移；数字/日期按表格 `data-locale` 序列化；公式只读格在预检阶段拦截，不会变成文本。页面逐格回执被逐格记账，部分拒绝不触发整块回滚；每块写入前重读版本与现值，行版本变化且该格现值偏离基线时判定为人工并发修改，保留冲突不覆盖。恢复时用页面现值与已确认回执对账，仅对仍缺的格生成新计划，不整块重贴。生产自动化应通过页面剪贴板粘贴路径，不直接调用页面函数或改写行数组；Chromium可使用授权clipboard权限或操作系统剪贴板。 门户的业务数据保存在本地来源服务中，关闭或重新打开浏览器不会撤销已接受的写入；页面data-saved可用于等待门户自身保存结束。状态接口只供门户运行，自动化不得直接调用它代替界面操作。
