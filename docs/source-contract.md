# 展位网格页面
两条业务行A-01、B-02含功率、联系人和只读公式。支持反向排序、数字locale切换和人工并发更改。页面在contenteditable单元格接收浏览器paste事件中的TSV，按当前视觉矩形逐格校验，功率大于100拒绝，其他单元格仍可成功。
回执写在页面status区，带业务键、列、版本和状态。现有查看器没有预览、确认或恢复逻辑。生产自动化应通过页面剪贴板粘贴路径，不直接调用页面函数或改写行数组；Chromium可使用授权clipboard权限或操作系统剪贴板。 门户的业务数据保存在本地来源服务中，关闭或重新打开浏览器不会撤销已接受的写入；页面data-saved可用于等待门户自身保存结束。状态接口只供门户运行，自动化不得直接调用它代替界面操作。
